راهنمای Asterisk Native Softphone

این پروژه چیست؟

این نرم‌افزار یک UI دسکتاپ Electron برای ویندوز است که تماس SIP کلاسیک را از طریق موتور Native یعنی PJSUA/PJSIP کنترل می‌کند. برخلاف نسخه WebRTC، این معماری برای اتصال UDP/TCP/TLS به Issabel/Asterisk طراحی شده است.

فایل ضروری

برای کار واقعی باید فایل زیر وجود داشته باشد:

tools\pjsua\pjsua.exe

بدون این فایل، UI اجرا می‌شود اما رجیستر و تماس واقعی انجام نمی‌شود.

کانفیگ پایه

Account Name: Sales 101
Server 1: 192.168.1.10
Extension / Username: 101
Password: password-of-extension
Transport: UDP
Port: 5060

صف و Ring Group

صف یا Ring Group در خود Issabel/Asterisk ساخته می‌شود. در سافت‌فون فقط شماره آن مقصد را می‌گیرید؛ مثلاً 600 یا 700.

اجرا

npm install
npm start

بیلد Portable

npm run dist:dir

نکات مهم

اگر Register خطا داد، ابتدا رمز داخلی، نوع Transport، پورت 5060، فعال بودن NAT/Firewall و نوع chan_sip یا pjsip در Asterisk را بررسی کنید.
